# Binary-tree reference scene

This scene draws a balanced binary search tree and animates preorder traversal: `8, 4, 2, 6, 12, 10, 14`.

## Demonstrates

- `circle` nodes with persistent IDs.
- Parent/child edges using `connector` objects with top/bottom anchors.
- A single cursor object moving through a non-linear traversal order.
- Per-node `fill` actions that accumulate visited state.
- Deterministic, fully declarative SceneDocument 1.0 geometry.

## Current limitations

- SceneDocument 1.0 has no tree/layout primitive; every node coordinate is authored explicitly.
- Edges do not perform obstacle-aware routing or automatic tree spacing.
- Traversal order is encoded as timeline actions rather than generated by executable recursion.
- The scene cannot create/remove nodes or dynamically change tree topology during playback.
